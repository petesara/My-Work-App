# ATS — Applicant Tracking System

Bilingual (English / Quebec French) Applicant Tracking System for Canadian face-to-face fundraising.

## Tech Stack
- React 18 + Vite
- React Router v6
- Tailwind CSS
- Zustand (localStorage persistence)
- IBM Plex Sans + IBM Plex Mono

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Roles
- **Recruitment**: Add candidates, manage pipeline, interview tracking
- **Admin**: Onboarding tracker, manager directory, reports
- **Operations**: View pipeline, monitor onboarding

## Keyboard Shortcuts
- `N` — Add new candidate (from Pipeline view)
- `Escape` — Close panel
